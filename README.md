# NewYork Larm Central

> A premium personal safety solutions website for a fictional alarm company. Features smart alarm buttons, a safety app, and 24/7 command center monitoring for businesses. Built with modern web technologies and an emphasis on stunning visual design and interactivity.

---

## Preview

Open `index.html` in any modern browser. No build tools or server required — everything loads via CDN.

---

## Tech Stack

| Technology             | Purpose                                                 |
| ---------------------- | ------------------------------------------------------- |
| **HTML5**              | Semantic structure                                      |
| **CSS3**               | Custom properties, Grid, Flexbox, animations, dark mode |
| **Vanilla JavaScript** | All interactivity without framework overhead            |
| **GSAP 3.12**          | ScrollTrigger animations, counters, reveals             |
| **Swiper 11**          | Touch-friendly industry/testimonial sliders             |
| **Lucide Icons**       | Consistent icon system                                  |
| **Google Fonts**       | Cormorant Garamond + DM Sans                            |
| **Unsplash**           | High-quality imagery via CDN                            |

---

## Features

- Animated preloader with progress bar
- Hero slideshow with particle effects
- Light / dark mode toggle with smooth transition
- Scroll-triggered GSAP animations
- Product cards with 3D tilt effect and category filters
- Industry slider (Healthcare, Hospitality, Construction, etc.)
- Testimonial carousel with autoplay
- Contact form with animated submit feedback
- Fully responsive design
- Gold-themed marquee banner
- Inline SVG social icons in footer
